# Nexlide

Nexlideは、Apple Pencil操作でPDFプレゼンを進めるためのiPadOSネイティブアプリです。ローカルPDFを1ページずつ表示し、外部ディスプレイ出力中はiPad側を発表者用のプレゼンモードとして使えます。

## 対応環境

- iPadOS 17.5以降
- iPad専用
- 横向き表示専用
- Xcodeで開けるSwift/SwiftUIプロジェクト
- PDFKitを使ったローカルPDF表示
- 外部サーバー、広告、サブスクリプションなし

## できること

- FilesアプリからPDFを選択して表示
- PDFを1ページ単位で全画面表示
- 画面右側タップで次ページ、左側タップで前ページ
- スワイプでページ移動
- キーボードの右矢印/Spaceで次ページ、左矢印で前ページ
- Apple Pencilのダブルタップ/スクイーズに機能を割り当て
- 各ページごとの原稿入力
- `.txt` / `.md` 原稿ファイルの取り込み
- 外部ディスプレイ接続時のプレゼンモード
- ダークモード固定UI
- iPad側はPDF選択後、横向きのプレゼンモードを基本画面として表示

## Apple Pencil操作

Nexlideは`UIPencilInteraction`を使い、Apple PencilからOSが通知する操作を検出します。

- ダブルタップ: `次ページ` / `前ページ` / `割り当てなし` を選択可能
- スクイーズ: `次ページ` / `前ページ` / `割り当てなし` を選択可能

Apple Pencilの機種名そのものを確実に取得する公開APIはありません。そのため、Nexlideでは「第2世代」「Pro」などの製品名を直接判定するのではなく、実際に検出できた操作から対応機能を扱います。

制限:

- Apple Pencil 第1世代はダブルタップ/スクイーズ非対応です。
- Apple Pencil 第2世代系では主にダブルタップが利用できます。
- Apple Pencil Proのスクイーズは、Apple Pencil Pro、対応iPad、対応iPadOSに依存します。
- 未対応環境では通常のタップ、スワイプ、キーボード操作を使ってください。

## 原稿ファイル

原稿はアプリ内で手入力できます。さらに、`.txt`または`.md`ファイルを取り込めます。Markdownは原稿表示時に反映され、見出し・箇条書き・強調・リンクなどを読みやすく表示します。

設定から、原稿モードを`OFF` / `Markdown` / `TXT`で切り替えられます。`OFF`では右側の原稿欄を閉じ、Now/Nextのスライドプレビューを横画面いっぱいに大きく表示します。原稿の文字サイズも設定で変更できます。

原稿はページにピン留めする方式です。区切り編集モードで左側のページ一覧からページを選び、その横の原稿欄へMarkdownを書くと、そのページに原稿が紐づきます。ピンがないページでは原稿は表示されず、Nowのページがピン留めされたページに進むと、右側の原稿表示もそのページの内容へ切り替わります。

ページ区切りは、行単独の`---`または`ーー`です。

```markdown
1枚目の原稿

---
2枚目の原稿

ーー
3枚目の原稿
```

## Nexlideプロジェクト

PDFと原稿を別々に管理すると、PDFを移動・リネームした時に原稿との紐づきが分かりにくくなります。そのためNexlideでは、PDFを選択した時点でアプリ内に`.nexlide`プロジェクトを作成します。

`.nexlide`はiPadOS上では1つのプロジェクトファイルとして扱う想定のパッケージです。内部には次のファイルを保存します。

- `presentation.pdf`: プレゼン本体
- `manifest.json`: 原稿ピン、ラップ履歴、現在ページ、原稿表示設定など

右下のメニューから、`.nexlide`プロジェクトを開く/書き出すことができます。書き出した`.nexlide`をFilesアプリやiCloud Driveに保存すれば、PDFと原稿を一塊としてバックアップ・共有できます。

## 外部ディスプレイ

外部ディスプレイ接続中は、iPad側がプレゼンモードになります。

- 左上: 現在のスライド
- 左下: 次のスライド
- 右上: 経過時間タイマー
- 右中央: 原稿
- 右下: 前へ/次へボタン

外部ディスプレイ側は設定から次を選べます。

- 現在スライドのみ
- プレゼンモード

## 使い方

1. Xcodeで`Nexlide.xcodeproj`を開きます。
2. iPad実機またはiPad Simulatorを選びます。
3. 必要に応じてBundle IdentifierとSigningを自分の環境に合わせます。
4. ビルドして起動します。
5. `PDFを選択`からFilesアプリ内のPDFを選びます。
6. 必要に応じて`原稿`から`.txt`/`.md`を取り込み、またはプレゼンモードで手入力します。
7. `設定`からApple Pencil操作と外部ディスプレイ表示を選びます。

## ビルド方法

このリポジトリには署名情報を含めていません。Xcodeで開いたあと、自分のApple Developer Teamを選択してください。

```sh
open Nexlide.xcodeproj
```

この作業環境ではXcode本体ではなくCommand Line Toolsが有効なため、`xcodebuild`での検証は実行できません。Xcode本体が有効な環境でビルドしてください。
